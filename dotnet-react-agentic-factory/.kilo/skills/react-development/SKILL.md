name: react-development
description: Use when implementing React/TypeScript UI, browser API clients or accessibility behavior.
---
Read the feature spec and backend contract. Define typed request/response boundaries and runtime validation of external JSON. Implement loading/empty/error/success states, semantic HTML and keyboard access. Keep secrets and authorization on the API. Use relative API routes. Add Testing Library behavior tests; add real browser acceptance tests when user journeys require them. Run typecheck, ESLint, format check, coverage, build and npm audit. Document UI startup instructions.
